# Spec Delta

## Purpose

Печать: печать и предпросмотр печати документов, диалог Print Curves с областью печати и параметрами графиков.

## ADDED Requirements

### Requirement: Print and print preview

Приложение SHALL предоставлять печать и предпросмотр печати для любого документа и SHALL позволять настраивать принтер.

#### Scenario: Печать документа
- **WHEN** пользователь выбирает «Print»
- **THEN** открывается диалог «Print Curves», после подтверждения открывается системный диалог настройки печати с возможностями печати в файл, диапазона и числа копий, и документ печатается

#### Scenario: Печатается только задание печати
- **WHEN** открывается системный диалог печати
- **THEN** в макет печати попадают только страницы задания (графики), а элементы интерфейса (меню, панель команд, вкладки, диалог и строка состояния) в макет не попадают

#### Scenario: Предпросмотр печати
- **WHEN** пользователь выбирает «Print Preview»
- **THEN** документ отображается в режиме предпросмотра с доступными переходом по страницам и изменением масштаба

#### Scenario: Отрисовка кривых при печати
- **WHEN** страница задания печати отображается в предпросмотре или печатается
- **THEN** на странице рисуется график семейства характеристических кривых, а также каждый выбранный график вкладки Charts, теми же представлениями, что и на экране

#### Scenario: Настройка принтера
- **WHEN** пользователь выбирает «Print Setup»
- **THEN** открывается системный диалог настройки принтера

### Requirement: Print Curves dialog

Диалог «Print Curves» SHALL позволять задавать область печати и параметры графиков.

#### Scenario: Выбор области печати
- **WHEN** открыт диалог «Print Curves»
- **THEN** доступны варианты «Entire document» (по умолчанию) и «Current page only», а также параметры «Smooth Curves», «Color Curves» и «Display Information»

#### Scenario: Область действия настроек печати
- **WHEN** пользователь изменяет настройки в диалоге «Print Curves» или в опциях
- **THEN** изменения действуют до их следующего изменения или до выхода из программы, а при новом запуске восстанавливаются значения по умолчанию

### Requirement: Print all charts on same page option

Опция «Print all charts on the same page» SHALL управлять размещением графиков при печати.

#### Scenario: Печать графиков вместе
- **WHEN** опция «Print all charts on the same page» включена (по умолчанию)
- **THEN** графики печатаются вместе на одной странице

#### Scenario: Печать графиков раздельно
- **WHEN** опция выключена
- **THEN** графики печатаются по отдельности, каждый крупнее и на своей странице
