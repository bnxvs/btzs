# Spec Delta

## Purpose

Ступенчатые клинья: импорт внешних клиньев, два хранимых по умолчанию клина, выбор активного клина и сохранение текущего клина в качестве клина по умолчанию.

## ADDED Requirements

### Requirement: Active step tablet

Каждый документ плёнки или бумаги SHALL использовать активный ступенчатый клин, чьи плотности отображаются во втором столбце таблицы данных.

#### Scenario: Отображение плотностей активного клина
- **WHEN** создаётся новый документ или открывается существующий
- **THEN** во втором столбце таблицы данных отображаются плотности активного клина (значения по умолчанию или ранее сохранённые в документе)

#### Scenario: Изменение плотностей клина
- **WHEN** пользователь заменяет значения клина в таблице данных
- **THEN** новые значения используются как клин текущего документа, и их можно сохранить как файл клина

### Requirement: Step tablet dialog

Меню File SHALL предоставлять диалог «Step Tablet», позволяющий импортировать клин из файла, выбрать один из двух сохранённых клиньев по умолчанию, просмотреть их и сохранить текущий клин как клин по умолчанию.

#### Scenario: Импорт клина из файла
- **WHEN** пользователь выбирает «Import a step tablet into the current document from a file» и указывает файл
- **THEN** клин импортируется, и приложение подтверждает успешный импорт; при непригодном или отсутствующем клине показывается соответствующее сообщение об ошибке

#### Scenario: Использование сохранённого клина по умолчанию
- **WHEN** пользователь выбирает «Use saved Step Tablet #1» или «Use saved Step Tablet #2»
- **THEN** соответствующий сохранённый клин становится активным для текущего документа

#### Scenario: Просмотр сохранённого клина
- **WHEN** пользователь выбирает «View Step Tablet 1» или «View Step Tablet 2»
- **THEN** отображаются значения ступеней соответствующего сохранённого клина

#### Scenario: Сохранение клина по умолчанию
- **WHEN** пользователь выбирает сохранить текущий клин как Step Tablet #1 или #2
- **THEN** при запросе подтверждения перезаписи и согласии текущий клин сохраняется под выбранным номером

### Requirement: Old format step tablet handling

При открытии файла устаревшего формата, не содержащего сведений о ступенчатом клине, приложение SHALL предложить импортировать клин для использования с этим файлом.

#### Scenario: Открытие файла устаревшего формата
- **WHEN** открывается файл старого формата без данных о клине
- **THEN** приложение предлагает импортировать ступенчатый клин для использования с этим файлом

### Requirement: Step tablet import from another Plotter file

Приложение SHALL позволять извлекать ступенчатый клин из другого файла Plotter (`.pfc`/`.ppc`).

#### Scenario: Импорт клина из файла Plotter
- **WHEN** пользователь выбирает файл Plotter, содержащий ступенчатый клин
- **THEN** клин извлекается; если файл не содержит клина, приложение сообщает об этом
