# Spec Delta

## Purpose

Локализация интерфейса приложения, включая полную русскоязычную локализацию, переключение языка, соблюдение региональных форматов чисел, дат и единиц измерения температуры.

## ADDED Requirements

### Requirement: Interface localization infrastructure

Приложение SHALL разделять весь отображаемый пользователю текст и данные интерфейса от кода, используя систему локализации с каталогами переводов, чтобы любой язык можно было добавить без изменения логики.

#### Scenario: Тексты вынесены в каталоги переводов
- **WHEN** интерфейс отрисовывается
- **THEN** все подписи меню, диалогов, кнопок, заголовков вкладок, подсказок и сообщений берутся из активного языкового каталога, а не жёстко заданы в коде

#### Scenario: Новый язык без изменения кода
- **WHEN** добавляется новый языковой каталог
- **THEN** приложение отображает интерфейс на этом языке без изменения исходного кода

### Requirement: Russian localization

Приложение SHALL предоставлять полную русскоязычную локализацию интерфейса, покрывающую все меню, диалоги, вкладки, панели инструментов, строку состояния, окно опций, окно «О программе», справку и сообщения об ошибках.

#### Scenario: Интерфейс на русском языке
- **WHEN** выбран русский язык
- **THEN** названия меню, пунктов, диалогов, вкладок, кнопок, подсказок и сообщений об ошибках отображаются на русском языке

#### Scenario: Охват справки и сообщений об ошибках
- **WHEN** выбран русский язык и пользователь открывает справку или вызывает ошибку (например, импорт кривой недопустимого типа)
- **THEN** содержимое справки и текст сообщения отображаются на русском языке

#### Scenario: Полнота перевода
- **WHEN** выбран русский язык
- **THEN** все элементы интерфейса (главные меню File/Edit/View/Match/Help, вкладки Family/Data/Analyze/Charts, Info/Film/Paper/Compare, диалоги Options, Curve Details, Family Details, Step Tablet, Print Curves, Import Curves, Arrange Curves, Manage Approximated Curves, печати) имеют русский перевод без оставшихся англоязычных фрагментов

### Requirement: Language selection and persistence

Приложение SHALL позволять пользователю выбирать язык интерфейса и SHALL запоминать выбор между запусками.

#### Scenario: Переключение языка
- **WHEN** пользователь выбирает русский язык в настройках (или системный язык — русский)
- **THEN** интерфейс немедленно или после перезапуска отображается на русском языке

#### Scenario: Сохранение выбора языка
- **WHEN** пользователь выбрал язык и перезапускает приложение
- **THEN** выбранный язык остаётся активным

#### Scenario: Язык по умолчанию
- **WHEN** пользователь ещё не выбирал язык
- **THEN** приложение использует язык системы, если для него есть каталог перевода, иначе язык по умолчанию

### Requirement: Locale-aware formatting

Числовые, датовые и температурные значения SHALL форматироваться согласно активному языку и региональным настройкам.

#### Scenario: Десятичный разделитель
- **WHEN** активен русский язык
- **THEN** числа отображаются и принимаются с запятой как десятичным разделителем

#### Scenario: Ввод дробного значения
- **WHEN** пользователь вводит в числовое поле дробное значение (например `0,015`) посимвольно
- **THEN** десятичный разделитель не теряется, значение принимается с сохранением введённой точности, а по завершении редактирования поле приводится к каноническому виду

#### Scenario: Формат даты
- **WHEN** активен русский язык
- **THEN** даты тестов отображаются в формате, принятом в русской локали (например, `ДД.ММ.ГГГГ`)

#### Scenario: Единицы температуры
- **WHEN** активен русский язык
- **THEN** приложение по-прежнему поддерживает выбор между Фаренгейтом (по умолчанию) и Цельсием и корректно подписывает единицы на русском языке

### Requirement: Domain terminology glossary

Приложение SHALL использовать согласованный глоссарий русскоязычных терминов для предметной области (кривая, семейство кривых, ступенчатый клин, плотность, проявитель, разведение, носок кривой (toe), вуаль (flare) и т. п.) во всех местах интерфейса.

#### Scenario: Единообразие терминов
- **WHEN** один и тот же предметный термин встречается в разных окнах
- **THEN** он переведён одинаково во всех местах интерфейса согласно глоссарию

### Requirement: Abbreviation legend

Вкладка Analyze SHALL показывать легенду, поясняющую используемые сокращения (EFS, G-bar, SBR, ES, DR, IDmin, IDmax, ISO-диапазон, класс) простыми словами на языке интерфейса.

#### Scenario: Пояснение сокращений
- **WHEN** открыта вкладка Analyze документа плёнки или бумаги
- **THEN** под таблицей анализа отображается легенда, где каждому сокращению дано краткое пояснение простыми словами
