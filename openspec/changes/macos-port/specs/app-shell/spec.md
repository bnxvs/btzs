# Spec Delta

## Purpose

Оболочка приложения в современном настольном стиле: одно окно с вкладками документов, команды, зависящие от типа документа, иконочная панель действий, строка состояния, подменю недавних файлов, справка и «О программе». Оболочка намеренно **не** воспроизводит оконную среду MFC 2003 года (MDI-окна каскадом/мозаикой, строковое меню, индикаторы режимов клавиатуры), чтобы интерфейс был понятен новым пользователям.

## ADDED Requirements

### Requirement: Tabbed document shell

Приложение SHALL открывать несколько документов одновременно в одном окне, отображая каждый документ отдельной вкладкой, и SHALL позволять переключаться между вкладками и закрывать их.

#### Scenario: Открытие нескольких документов
- **WHEN** пользователь создаёт или открывает более одного документа
- **THEN** каждый документ отображается отдельной вкладкой в верхней области окна, активная вкладка выделена, а при переключении вкладки показывается содержимое соответствующего документа

#### Scenario: Закрытие документа с несохранёнными изменениями
- **WHEN** пользователь закрывает вкладку документа с несохранёнными изменениями
- **THEN** приложение предлагает сохранить изменения («Save changes to %1?») до закрытия

### Requirement: Document-type-specific commands

Набор доступных команд SHALL зависеть от типа активного документа и содержать действия, соответствующие этому типу.

#### Scenario: Команды документа плёнки или бумаги
- **WHEN** активен документ Film или Paper
- **THEN** доступны команды New Film/New Paper/New Matcher, Open, Close, Save, Save As, Step Tablet…, Print…, Print Preview, Print Setup…, список недавних файлов и Exit

#### Scenario: Команды документа Matcher
- **WHEN** активен документ Matcher
- **THEN** доступна группа Match с командами «Load new Film…», «Load new Paper…», «Approximate Curves…», «Save current Match for Comparison», «Load Match for Comparison…», «Load Reference Curve…», «Use Default Reference Curve», «Use Loaded Curve», а также «Restore File Defaults» в группе Edit

### Requirement: Command bar and status line

Приложение SHALL предоставлять панель действий с иконочными кнопками для быстрого доступа к основным командам активного документа и строку состояния с контекстной подсказкой.

#### Scenario: Иконочные кнопки панели действий
- **WHEN** курсор задерживается над кнопкой панели действий
- **THEN** показывается всплывающая подсказка с названием команды, а в строке состояния — краткое описание её назначения

#### Scenario: Строка состояния
- **WHEN** документ открыт
- **THEN** строка состояния показывает имя активного документа, признак несохранённых изменений и подсказку активной команды

#### Scenario: Сообщение об ошибке команды
- **WHEN** команда завершается сбоем (например, при открытии файла или создании документа Matcher)
- **THEN** в строке состояния отображается причина сбоя, а ошибка не проглатывается молча
- **WHEN** пользователь отменяет создание документа Matcher
- **THEN** в строке состояния сообщается об отмене

### Requirement: Document tabs

Окно документа SHALL содержать вкладки, зависящие от типа документа: `Family`, `Data`, `Analyze`, `Charts` для плёнки и бумаги; `Info`, `Film`, `Paper`, `Compare` для Matcher.

#### Scenario: Вкладки нового и открытого документа плёнки/бумаги
- **WHEN** создаётся новый документ Film или Paper
- **THEN** открывается вкладка `Data`, готовая к вводу данных, а прочие вкладки пусты до завершения ввода
- **WHEN** открывается существующий файл Film или Paper
- **THEN** документ открывается на вкладке `Family`

#### Scenario: Вкладки документа Matcher
- **WHEN** создаётся или открывается документ Matcher
- **THEN** документ открывается на вкладке `Info`, доступны вкладки `Film`, `Paper` и `Compare`

### Requirement: Recent files list

Меню File SHALL содержать список последних открытых файлов и пункт его очистки.

#### Scenario: Открытие файла из списка последних
- **WHEN** пользователь выбирает файл из списка последних файлов
- **THEN** этот файл открывается, а список обновляется, помещая выбранный файл первым

### Requirement: Help and About

Меню Help SHALL предоставлять переход к темам справки, переход на сайт BTZS.org и окно «About».

#### Scenario: Открытие справки
- **WHEN** пользователь выбирает «Help Topics» или нажимает F1
- **THEN** открывается встроенная справка приложения

#### Scenario: Окно «О программе»
- **WHEN** пользователь выбирает «About Plotter for Windows…»
- **THEN** показывается окно About с названием и версией продукта, а также сведениями об авторских правах BTZS Software и Phil Davis

### Requirement: Locale-aware numeric input and display

Приложение SHALL следовать региональным настройкам системы для числового ввода и отображения (разделитель целой и дробной части, форматы даты и времени).

#### Scenario: Соблюдение региональных настроек
- **WHEN** система настроена на локаль, использующую запятую как десятичный разделитель
- **THEN** приложение принимает и отображает числа с этим разделителем во всех числовых полях

### Requirement: Graph clipboard copy

Приложение SHALL позволять копировать текущий вид анализа в системный буфер обмена.

#### Scenario: Копирование графика
- **WHEN** пользователь нажимает Ctrl+C при активном виде анализа
- **THEN** текущий график помещается в системный буфер обмена как изображение для вставки в другие приложения
