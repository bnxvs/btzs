# Proposal

## Why

«Plotter for Windows» (BTZS Software, автор Phil Davis) — приложение для сенситометрического анализа чёрно-белых фотоматериалов: построение семейств характеристических кривых по денситометрическим данным, расчёт эффективной светочувствительности (EFS), средней градиентности (G-bar), диапазона яркостей сюжета (SBR) для плёнок, а также ES/DR/ISO-диапазона и класса контраста для фотобумаг. Приложение 32-битное, MFC/VC7, существует только под Windows и не поддерживается. Оригинальные файлы данных (`.pfc`, `.ppc`, `.pmf`), методики и накопленные пользовательские архивы тестов нужно сохранить, а доступ к инструменту вернуть на современном оборудовании.

Этот change описывает полное воспроизведение функциональности «Plotter for Windows» v1.2 в виде кроссплатформенного веб-приложения (React + TypeScript) с нативной упаковкой для macOS.

## What Changes

- Новое кроссплатформенное приложение `Plotter` на React + TypeScript, упаковываемое для macOS (и потенциально Windows/Linux) как настольное приложение.
- Воспроизведение типов документов: Film (`.pfc`), Paper (`.ppc`), Matcher (`.pmf`) и служебных диалогов (Step Tablet, Options).
- Воспроизведение окон-вкладок документа: Film/Paper — `Family`, `Data`, `Analyze`, `Charts`; Matcher — `Info`, `Film`, `Paper`, `Compare`.
- Воспроизведение расчётного ядра: точки скорости (Approx CI, 0.1 over FB+F, Personal Speed Point), EFS, G-bar, SBR, ES, flare, коррекция экспозиции, зоны, N-числа, а для бумаги — IDmin/IDmax, DR, ES, ISO Range, класс носка (toe).
- Воспроизведение графиков: 6 плёночных (Dev. Time/SBR, Dev. Time/G, Dev. Time/N, EFS/SBR, EFS/G, EFS/N) и 2 бумажных (ISO Range Chart, Paper Grade Chart), включая инструмент Track.
- Полная двусторонняя совместимость с бинарными форматами BTZS: чтение **и** запись `.pfc`, `.ppc`, `.pmf`, импорт устаревших Macintosh PlotterPlus и DOS Plotter файлов.
- Современная оболочка приложения: одно окно с вкладками документов, иконочная панель команд, строка состояния, список последних файлов, справка и «О программе». Оконная среда MFC 2003 года (MDI-окна каскадом/мозаикой, строковое меню, индикаторы режимов клавиатуры) намеренно не воспроизводится.
- Подсистема локализации с полной русскоязычной локализацией интерфейса и возможностью добавления других языков.
- **BREAKING** (для целевого проекта): приложение создаётся с нуля; публичного API для сохранения обратной совместимости не существует.

## Capabilities

### New Capabilities
- `app-shell`: современная оболочка приложения — одно окно с вкладками документов, команды по типам документов, иконочная панель команд, строка состояния, список последних файлов, справка и «О программе», копирование графика в буфер.
- `film-documents`: документы плёнки — ввод данных по ступенчатому клину, детали семейства кривых, детали кривой, управление кривыми (удаление, упорядочивание, импорт), сохранение/открытие `.pfc`.
- `paper-documents`: документы бумаги — ввод данных, детали семейства бумаги, детали кривой (ID/Name), параметр IDmin %, сохранение/открытие `.ppc`.
- `curve-analysis`: расчётное ядро анализа — точки скорости и Personal Speed Point, EFS, G-bar, SBR, ES, flare, коррекция экспозиции, зоны и N-числа; для бумаги — IDmin/IDmax, DR, ES, ISO Range, класс носка.
- `charts`: вкладка графиков — 6 плёночных и 2 бумажных графика, переключение, инструмент Track, пересчёт при изменении параметров.
- `matcher`: документы Matcher — вкладки Info/Film/Paper/Compare, ссылки на файлы плёнки/бумаги, переопределение параметров анализа, приближённые кривые, эталонные (reference) кривые, сравнение сопоставлений, сохранение/открытие `.pmf`.
- `step-tablet`: ступенчатые клинья — импорт, два хранимых по умолчанию клина, активный клин, сохранение клина по умолчанию.
- `file-formats`: бинарные форматы BTZS — чтение и запись `.pfc`/`.ppc`/`.pmf`, импорт устаревших форматов, регистрация типов документов.
- `printing-and-export`: печать, предпросмотр печати, настройка печати и диалог Print Curves.
- `program-options`: окно опций и значения по умолчанию — параметры анализа, отображения, ширины линий, печати, эталонной кривой, Personal Speed Point; восстановление значений по умолчанию; область действия настроек.
- `localization`: система локализации интерфейса — каталоги переводов, полная русская локализация, выбор и запоминание языка, региональные форматы чисел/дат/единиц, глоссарий предметных терминов.

## Impact

- Новый код: веб-приложение React + TypeScript, включая модуль разбора/записи бинарных форматов BTZS.
- Новые зависимости: среда сборки (Vite/аналог), библиотека графиков, библиотека упаковки в настольное приложение macOS.
- Совместимость данных: форматы `.pfc`/`.ppc`/`.pmf` должны оставаться полностью взаимно читаемыми с исходным Windows-приложением.
- Справочные материалы: извлечённое из инсталлятора приложение `Plotter.exe`, файлы справки (`.htm`), примеры данных в `app/`, MSI/CAB (`msi/`) и распакованные ресурсы (`exeres/`) используются только как источник требований.
- Никаких изменений в существующем исходном коде (его нет) — только создание новой кодовой базы в рамках последующей реализации.
