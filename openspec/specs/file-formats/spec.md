# file-formats Specification

## Purpose
Совместимость с файловыми форматами BTZS: чтение и запись бинарных файлов плёнки, бумаги и Matcher, импорт устаревших форматов Macintosh PlotterPlus и DOS Plotter.

## Requirements

### Requirement: Binary film and paper format read/write

Приложение SHALL читать и записывать файлы плёнки `.pfc` и бумаги `.ppc` в бинарном формате BTZS, взаимно совместимом с исходным Windows-приложением.

#### Scenario: Идентификация формата
- **WHEN** приложение открывает файл
- **THEN** оно распознаёт формат по сигнатуре (для плёнки и бумаги — `BTZSFILM`/`BTZSPAPR`) и отвергает файлы с недопустимым форматом с сообщением об ошибке

#### Scenario: Чтение файла плёнки или бумаги
- **WHEN** открывается файл `.pfc` или `.ppc`, созданный исходным приложением
- **THEN** корректно восстанавливаются параметры семейства, ступенчатый клин, все кривые с их данными и параметрами, а также параметры анализа

#### Scenario: Запись файла, читаемого исходным приложением
- **WHEN** приложение сохраняет документ плёнки или бумаги
- **THEN** полученный файл открывается исходным Windows-приложением с теми же данными

#### Scenario: Круговая совместимость
- **WHEN** файл пересохранён новым приложением и вновь открыт им же
- **THEN** все параметры, кривые, клин и анализ восстанавливаются без потерь

### Requirement: Matcher binary format read/write

Приложение SHALL читать и записывать файлы Matcher `.pmf` в бинарном формате BTZS.

#### Scenario: Чтение и запись `.pmf`
- **WHEN** приложение открывает и сохраняет файл `.pmf`
- **THEN** восстанавливаются и сохраняются ссылки на плёнку и бумагу, выбранные кривые, приближённые кривые, эталонная кривая и сохранённые сравнения сопоставлений

#### Scenario: Недопустимая сигнатура `.pmf`
- **WHEN** открывается файл с расширением `.pmf`, не являющийся допустимым файлом Matcher
- **THEN** приложение сообщает о недопустимом или повреждённом формате

### Requirement: Legacy format import

Приложение SHALL открывать файлы, созданные устаревшими версиями — Macintosh PlotterPlus и DOS Plotter, — конвертируя их во внутреннее представление.

#### Scenario: Импорт файла PlotterPlus или DOS Plotter
- **WHEN** пользователь открывает файл устаревшего формата
- **THEN** приложение считывает доступные данные кривых и параметров, а при отсутствии сведений о ступенчатом клине предлагает его импортировать

### Requirement: Document type registration and file associations

Система SHALL регистрировать три типа документов с собственными расширениями, значками и фильтрами открытия.

#### Scenario: Фильтры открытия файлов
- **WHEN** пользователь открывает файл
- **THEN** доступны фильтры «All Plotter Files (*.pfc; *.ppc; *.pmf)», «Plotter Film Curves (*.pfc)» и «Plotter Paper Curves (*.ppc)» помимо фильтра всех файлов

#### Scenario: Ассоциация расширений с типами документов
- **WHEN** приложение открывает файл по расширению
- **THEN** `.pfc` открывается как документ плёнки, `.ppc` — как документ бумаги, `.pmf` — как документ Matcher
