# Формат файлов BTZS — результаты реверса

Observed from: 68 film files `app/*.pfc*`, 9 paper files `app/*.ppc*`, `app/D100RefCrv.pmf2`.
Все многобайтовые значения — little-endian. Строки — `u32 длина` + байты (CP1251).

## Общий заголовок (0x00..0x48)

| Смещение | Тип | Наблюдение |
|---|---|---|
| 0x00 | char[8] | магия: `BTZSFILM` (плёнка), `BTZSPAPR` (бумага), `BTZSPAP` (Matcher/ref) |
| 0x08 | u32 | маркер: 104 у плёнки, 103 у бумаги |
| 0x0c..0x48 | 60 байт | блок настроек анализа/отображения (raw, сохраняется как есть) |
| 0x40 | u32 | «неизвестно», обычно 0 |
| 0x44 | u32 | число строк (обычно 10) |

Внутри блока 0x0c..0x48 наблюдаются два `double` (0.9 и 1.05/1.0) и ряд `u32` (1,4,1,0,0,0).

## Строки после 0x48 (10 штук)

| # | Плёнка | Бумага |
|---|---|---|
| 0 | Дата | Дата |
| 1 | Имя плёнки | Имя бумаги |
| 2 | Проявитель | Проявитель |
| 3 | Разведение | Разведение |
| 4 | Примечания | Примечания |
| 5 | (пусто) | Способ печати (contact/projection) |
| 6 | (пусто) | Время/температура |
| 7 | (пусто) | Тонер/сушка |
| 8 | Рабочий объём («2 oz/sheet») | (пусто) |
| 9 | (пусто) | (пусто) |

## После строк

| Тип | Поле |
|---|---|
| f32 | версия формата (напр. 1.875, 2.53125) |
| u32 | ISO (напр. 100) |
| double | температура °F (70 плёнка, 68 бумага) |
| u32 | флаг (обычно 1) |
| u32 | число ступеней клина (обычно 21) |

Затем клин: `count × (u8 номер ступени + double плотность)`.

## Кривые

```
u32 curveCount
повтор curveCount раз:
  u32 labelLen + label      // время проявления (плёнка) или ID/Name (бумага)
  u32 noteLen  + note       // примечание к кривой
  reserved[N]             // сохранённые байты (N: плёнка 20; бумага 4, иногда 20)
  u32 pointCount
  pointCount × (u8 step + double density)
```

`reserved` для первой бумажной кривой обычно начинается с `01 00 00 00` (флаг),
остальные — нули; у плёнки — нули.

## Размер reserved (уточнено)

Размер `reserved` однозначно определяется маркером из 0x08:

| Маркер | Тип файла | reserved |
|---|---|---|
| 100 | старая плёнка (DOS/Efke-совместимая) | **4** |
| 103 | бумага | **4** |
| 104 | плёнка (текущий формат) | **20** |

Проверено полным разбором до конца файла на всех 152 образцах (`app/*.pfc*`,
`app/*.ppc*`) — расхождений нет. Ранее ошибочно считалось, что маркер 100
использует 20 байт.

## Маркер 100 (старая плёнка)

Единственный образец — `Delta_100_761.pfc3` (1409 байт). Отличия от 104:
- блок настроек короче: 0x0c..0x30 (36 байт), строки начинаются с 0x30;
- reserved кривой — 4 байта;
- порядок строк совпадает с 104 (date, name, developer, dilution, notes, '', '', '', volume, agitation).

## Matcher (`.pmf`)

`D100RefCrv.pmf2` (442 байта) использует магию `BTZSPAP` и иной заголовок.
Полный разбор (проверен побайтовым круговым совпадением):

| Смещение | Тип | Значение в образце |
|---|---|---|
| 0x00 | char[8] | `BTZSPAP` + байт версии `0x92` |
| 0x08 | u32 | 5 — версия `.pmf` |
| 0x0c | u32 | 1 |
| 0x10..0x60 | f64 ×10 | эталонные серые: 0.04, 1.885, 0.04, 0.1116, 0.2531, 0.5011, 0.8755, 1.3001, 1.6474, 1.885 |
| 0x60 | ref | ссылка на плёнку: u32 code(0) + pascal-строка `Delta 100 76+1.pfc` + u32 mtime (1002349011) |
| 0x7b | ref | ссылка на бумагу: u32 code(5) + pascal-строка `Composite Curve.ppc` + u32 mtime (1002349017) |
| 0x97 | u8[48] | непонятый блок (сохраняется как есть) |
| 0xc7 | u32 | число приближённых кривых (в образце 1) |
| … | запись кривой | u32 code(1=SBR) + u32-строка метки `SBR ~ 7.00` + u32(0,0,1) + f64 значение(7) + u32(0) + u32 pointCount(21) + точки (u8 ступень + f64 плотность) |
| 0x1b6 | u32 | замыкающее значение (0) |

Ссылки используют pascal-строки (u8 длина), в отличие от остальных строк BTZS
(u32 длина). Единственный доступный образец `.pmf` разобран до конца файла;
семантика полей `code`, блока 48 байт и трёх u32 перед значением не
подтверждена и сохраняется «как есть».

## Устаревшие форматы (Macintosh PlotterPlus / DOS Plotter)

Сигнатуры `FILMPLOT` (плёнка) и `PAPRPLOT` (бумага). После сигнатуры идёт
поток `float32` (little-endian); серия из 21 подряд идущего правдоподобного
значения плотности (0.01 ≤ d ≤ 3.5) трактуется как кривая. Клин в файле
отсутствует — после импорта предлагается его импортировать.
